# project-pcos
Polycystic Ovary Syndrome (PCOS) is a common endocrine disorder among
reproductiveage women, characterized by hormonal imbalances, irregular menstrual cycles,
and metabolic challenges. This study investigates the effectiveness of a logistic regression
model in predicting the presence of PCOS using lifestyle, clinical, and hormonal attributes.
After comprehensive preprocessing and exploratory analysis including correlation matrices
and heatmaps a logistic regression model was developed and evaluated. The model achieved
an accuracy of 89.8%, demonstrating a strong potential for clinical applicability in early PCOS
screening.
